### 提交代码到GitHub仓库流程：
1. 先fork原仓库，在github上创建仓库副本，再clone到本地，**==创建属于自己的分支==**，进行修改
2. 先git status确认自己分支的文件状态，确保文件在工作区
3.  git add "文件相对路径（从仓库目录开始）"，添加到暂存区
4. git diff --stage 查看文件修改的“差异”（新增/删除了哪些代码行），是提交前检查代码、防止误删或泄露的必备防线。
5. git commmit -m "pr标题名" 将文件提交到本地仓库
6. git status 再次查看文件状态
7. git push origin (个人分支名) 将个人分支推送到远程仓库
8. 提交pr
